# 海外 B2B 手串原料分销 — 项目文件夹

这个目录存放"手串珠子海外 B2B 分销"方向的调研资料和后续开发的工具/程序。跟 `bracelet-designer/`（面向 C 端店主的配置器工具）是两个不同方向，但共享同一个 crystal 项目背景。

## 目录结构

```
overseas /
  README.md              本文件
  research/               调研资料（市场分析、竞品、供应商筛选标准与案例）
  tools/                  后续开发的程序（比如供应商询盘/评估自动化工具）
```

## 业务方向简述

不做 C 端零售（退换货成本个人扛不住），改做 B 端：帮海外的小型 bead bar / 新手 Etsy 卖家 / 小众珠宝品牌，提供「精选质检过的散珠供应 + 可直接嵌入他们自己网站的手串配置器工具」。差异化在于把"货源筛选"和"配置器技术"打包，这个组合目前调研下来没有直接竞品在做。
