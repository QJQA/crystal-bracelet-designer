# 供应商筛选标准（三层筛查清单）

## 第一层：公司资质筛查

| 检查项 | 怎么查 | 红旗信号 |
|---|---|---|
| 统一社会信用代码（18位USCC） | 要求对方提供，中国合法企业必须公开，法律要求 | 拒绝提供 = 直接淘汰 |
| Alibaba金牌供应商认证 | 平台上直接看标识 | 无认证不代表不行，但有认证是加分项 |
| 近期订单/评价活跃度 | 看"从XX年至今"的资历是否匹配近6个月真实订单量 | 挂着老资历但近半年零订单零评价，可能是买来的空壳账号 |
| 沟通质量 | 问技术细节看回复是否具体 | 用"高奢质感""近似钻石"这种模糊话术、不主动披露材质真实情况的，淘汰 |
| 视频看厂 | 要求视频通话实拍原料区/工位 | 犹豫、只给固定角度、镜头"卡住"不动 = 红旗 |
| 响应速度 | 观察首次回复时长 | 参考基准：优秀供应商平均响应 ≤2小时 |

## 第二层：产品真实性核验（针对每一批珠子）

| 检查项 | 怎么做 |
|---|---|
| 书面材质说明 | 要求写清楚：具体石种名称、尺寸公差、孔径、是否染色/热处理/上蜡——良心商家会主动披露处理工艺 |
| 第三方检测报告 | 高价值石种要求GIA/IGI/GRS或国家级检测机构证书，证书编号要能在官网独立查验 |
| 先小样后大货 | 批量下单前必须先拿实物小样，核对颜色/尺寸/孔径跟描述是否一致 |
| 免费样品政策 | 是否愿意为新客户提供免费样品（好供应商的常见做法） |
| 起订量(MOQ)透明度 | 是否明确写出MOQ，还是含糊其辞 |

## 第三层：拿到样品后，自己能做的低成本鉴定

- **10倍放大镜看内含物** — 天然石有天然瑕疵/内含物纹理，人工/合成的会显得"太干净"
- **比重测试** — 例如染色料石比重约2.6，真青金石比重2.7-2.9，比重差能分辨仿冒
- **丙酮棉签测试** — 蘸丙酮在不显眼处快速擦拭，棉签上出现颜色说明是染色的（测完立刻用湿布擦干净）
- **手感/温度/雾气测试** — 真石头导热快、呵气雾气消散快

> 重要提醒：治理过的天然石（heat-treated/dyed）本身不等于假货，只要是天然开采（非实验室合成/仿制），依然算天然宝石——关键是**供应商是否主动披露处理工艺**，而不是处理本身。
