# 单位经济模型与履约模式调研

## 一、单位经济：毛利空间是否存在？

**上游成本（1688/工厂直采）**：
- 8mm天然水晶散珠（45-47颗/串）：粉水晶 $0.9/串，紫水晶 $2.3/串，黄水晶 $2.6/串，海蓝宝 $3/串
- 2-3cm水晶原石碎石（50颗/kg）：紫水晶 $8/kg，粉水晶（椭圆形）$17/kg

**终端零售价对比**：
- 同规格8mm粉水晶散珠，零售价 $9-11/串（eBay/GemWholesales）
- National Facets同类精工款 $40+/串

**结论：工厂到零售之间有约10倍的价差空间**，中间环节（分销/策展/物流/营销）有真实的毛利可以分配，模式在数字上不是"一上来就没利润"，这是好消息。

## 二、履约模式：Sourcing Agent vs Dropshipping Agent

两者核心区别：

| | Sourcing Agent（采购代理） | Dropshipping Agent（代发货代理） |
|---|---|---|
| 干什么 | 找货、验货、协助大批量采购/发运/收货 | 全链路服务，包库存+按单履约，你完全不碰货 |
| 适合谁 | 大批量批发采购的生意 | 每单直接单独寄给终端个人买家的生意 |
| 收费方式 | 订单总额3-10%佣金，或按项目收固定服务费 | 产品按工厂价（不加价），单独收每单的服务费 |
| 例子 | 专业买手/传统外贸代理 | ShipAnt / NicheDropshipping / BuckyDrop |

**关键判断依据不是"哪个更好"，而是你的下游B端客户的典型下单形态**：
- 如果每个海外小商家（bead bar/新Etsy卖家）是**分散地址、小额多次**下单（比如每次$50-200的散珠补货）→ 履约形态其实跟"每单寄给一个独立地址"很像，Dropshipping Agent这类服务反而更合适，因为他们本来就是为"很多单、发往很多不同地址"设计的，不管收件人是消费者还是小商家
- 如果下游客户是**大额低频**下单（比如一次性囤$2000+的货）→ 更接近Sourcing Agent的服务形态（批量采购+集运）

**⚠️未解决的问题：目标客户的典型下单金额/频率是多少，搜索引擎查不到（问了多个bead bar franchise相关查询，结果都是"因店而异，没有标准数据"）。这个信息本质上需要直接问真实的目标客户才能拿到，无法单靠继续搜索解决。**

## 三、意外发现：验证到了真实的客户痛点

Etsy宝石散珠/套件的评价里，**反复出现的第一大投诉是"颜色跟图片不符"**——照片显得色彩浓郁，实物收到后颜色很淡/发白，是最常见的"not as described"投诉类型。质量本身大部分评价是正面的，问题集中在"图文不符"上。

**这是一个可以直接被"策展+工具"模式解决的真实痛点**：
- 供应端：坚持要求供应商提供真实拍摄的样品照片，而非美化过的图库图，纳入筛选标准
- 工具端：如果未来把配置器的珠子渲染从模拟换成真实拍摄照片（之前就规划好的路线），"所见即所得"本身就是一个针对这个痛点的卖点

## 四、另一个真实风险：报关归类复杂度

美国海关对"散珠"的HS编码归类，处理程度不同税率天差地别：
- 未加工的天然/半宝石原石：HS 7103.10.2000，**免税**
- 经过切割/粗锯的宝石：HS 7103.10.4000，**21%从价税**
- 玻璃散珠：HS 7018.10，通常免税
- 成品串珠饰品：HS 7117（仿真饰品），约**11%关税**

我们卖的水晶珠子基本都经过切割抛光，很可能落在"已加工"这个更高税率区间，归类错误可能导致罚款/审计。**这进一步说明为什么该用有经验的履约代理（他们本来就熟悉这套归类规则），而不是自己摸索报关。**

## 五、当前结论

1. 单位经济：✅ 数字上有空间，值得继续推进
2. 客户下单形态（决定用哪种履约模式）：❌ 未解决，需要直接接触真实目标客户才能拿到，纯搜索无法解决
3. 客户真实痛点：✅ 找到了（图文不符/颜色失真），且正好是"策展+工具"模式能直接解决的
4. 报关归类风险：✅ 已识别，结论是必须依赖专业履约代理而非自己摸索
