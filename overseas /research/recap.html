调研复盘 · 8 个阶段

从「串珠工具」到「B2B 供应链」
这几轮到底聊出了什么

手串配置器工具做出来之后，讨论方向逐渐转向了海外 B2B 分销生意。这页把中间的每一次转折、每一个关键发现按时间顺序理出来，方便一次看完全貌。

调研时间线

0
起点：C 端还是 B 端？ 已决策

C 端零售必然伴随样式不符、尺寸不合适的退换货问题，个人运营扛不住。决定放弃 C 端直营，转向服务"会自己定制化再卖给消费者"的 B 端商家。

1
竞品与市场调研 已验证

海外确实有人把这行生意做成了完整闭环：免费网页工具（Crystal Weave）→ 高客单价配置器电商（Lucid Compose，$29.99 起）→ 线下连锁体验店（Little Words Project，$35/人）。

市场规模上，散珠/耗材市场约 $20-25B，定制珠宝市场规模更大、增速更快（不同报告口径 $1.6B-42B 不等）。

2
B2B 方向分析 已验证

散珠供应这一环已经很拥挤——Alibaba 上 1,658+ 家水晶珠供应商，加上 Fire Mountain / Halstead 这类经营几十年的成熟批发商，单纯"倒买倒卖"很难有壁垒。

真正的缺口是"太小谈不上工厂直供、又吃不下成熟批发商规模"的小型新入局者这一层——差异化方向是把「配置器工具」和「筛选过的供应」打包卖，目前没有直接竞品在做。

3
供应商筛选标准 已产出

整理出三层筛查清单：公司资质（统一社会信用代码、响应速度、视频看厂）→ 产品真实性（处理工艺披露、第三方检测、先样后货）→ 物理鉴定（放大镜、比重测试、丙酮测试）。

4
供应商案例：印度还是义乌？ 已决策

National Facets（印度 Jaipur）筛选标准几乎满分，但定位偏中高端——普通圆珠一串 $40+（vs 市面 $9-11），且他们本来就直接对全球批发，插一手当分销商赚不到差价。

决定供应端锚定义乌：价格带更贴近目标客户，且作为国内买家有主场优势。

5
义乌供应链调研 已验证

水晶珠子集中在国际商贸城一区二三楼；产业规模近万家企业、年产值超千亿。查证了"诚信通"只是入场券（交钱+营业执照即可开通），真正管用的是视频验厂、索要水电单、小批量试单。

⚠️ 风险信号：义乌饰品出口对美国、印度依赖度不低，行业报告明确提示两地都面临贸易政策风险。

6
模式调整：不碰线下 已决策

用户明确不想处理线下验厂这类麻烦事，精力要放在网站搭建、SEO、社媒上。转向依托 1688 平台的担保交易 + 跨境代发服务商，把物流和资金保障都交给现成的基础设施。

7
单位经济与履约模式深挖 数字验证

工厂价（$0.9-3/串）到零售价（$9-40/串）之间约有10倍价差空间，模式在数字上是站得住的。

意外的重要发现：Etsy 散珠评价里排第一的投诉永远是"颜色跟照片不符"——这正好是"策展+真实拍摄+工具所见即所得"能直接打的真实痛点，不是凭空想的概念。

同时识别出一个风险：美国海关对"切割过的宝石"按 21% 从价税征收（未加工原石则免税），归类错误代价不小。

8
当前卡点 待解决

该用 Sourcing Agent 还是 Dropshipping Agent，取决于目标客户"典型一单下多少钱、多久下一次"——这个数字搜索引擎查不到，需要直接接触真实的海外小商家才能拿到。这是目前唯一一个纯调研解决不了的缺口。

Sourcing Agent vs Dropshipping Agent 到底是什么

这两个词看着像同类东西，其实是完全不同的两种角色，用两个生活里的类比来区分。

采购代理

Sourcing Agent

你可以理解成你的私人采购员。你告诉他"我要买100公斤水晶珠子"，他去帮你找工厂、验货、砍价，然后把这一整批货打包运到一个地方（比如你自己的仓库）。

货到了之后怎么再分给你的一个个客户，是你自己接下来要处理的事，他不管这一段。

类比：批发市场里帮你跑腿砍价、把一卡车货给你拉到仓库门口的跑腿师傅。一次服务，交付一整批货。
  • 收费方式：订单总额 3-10% 佣金，或按项目收固定费
  • 适合：大额、低频、囤货型采购
代发货代理

Dropshipping Agent

你可以理解成帮你管快递的员工。你网站上每接到一个客户订单——哪怕只是一小包珠子——你就把"发给谁、发什么"告诉他，他直接从货源那边打包，直接寄到你客户手上。

你自己从头到尾不碰货、不打包、不用去寄快递，只负责转发订单信息。

类比：帮你把仓库和快递员都包了的代运营团队。每一单单独处理，直接送到最终收件人手上。
  • 收费方式：产品按工厂价（不加价），每单单独收服务费
  • 适合：分散地址、小额多次、不想囤货的生意
该选哪个：如果你的海外客户是"每次小几十到一两百美元、分散在不同地址、隔三差五下单补货"，这个形态更像 Dropshipping Agent 擅长的事——他们本来就是为"很多单、发往很多不同地址"设计的。如果客户是"一次囤几千美元的大货"，则更接近 Sourcing Agent 的服务形态。目前还不知道你的目标客户是哪一种，这也是阶段 8 那个待解决的缺口。

消化完之后

这几轮的结论基本收敛成一句话：模式在数字上和差异化上都站得住，但"该用哪种履约方式"这一个关键变量，需要直接接触几个真实的海外小商家才能拿到答案——纯网上搜索已经查到头了。
