# CRYSTAL STORE OS · 宣传官网

这是面向水晶手串、散珠和定制饰品门店的产品宣传官网，与店铺 SaaS Demo 分开维护。

## 文件说明

- `index.html`：官网页面；
- `style.css`：官网视觉样式；
- `script.js`：导航、FAQ 和页面动效；
- `website-og.png`：社交分享预览图；
- `.openai/hosting.json`、`sites-worker.js`：官网托管配置。

本地打开官网时，页面上的体验按钮会跳转到相邻的 `store-saas` 项目。
