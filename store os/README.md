# 晶石店铺助手 Demo

这是《手串报价与库存管理系统 PRD V0.2》的手机网页版流程 Demo。

## 体验方式

在项目目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8765
```

然后在浏览器打开：

```text
http://localhost:8765
```

PC 管理后台：

```text
http://localhost:8765/admin.html
```

也可以直接双击 `index.html` 使用。

## 推荐演示流程

1. 输入托盘编号 `01`；
2. 选择尺寸 `8mm`，再选择“紫水晶 · 8mm”；
3. 输入数量并加入报价单；
4. 切换到“商品搜索”，输入“紫水晶”并选择尺寸；
5. 点击右下角报价单圆球，添加手工费并确认成交；
6. 进入“库存”，查看两个托盘及 SKU 总库存的同步变化；
7. 进入“销售记录”，查看成交明细。

## Demo 特性

- 托盘搜索与商品搜索并列，默认使用托盘搜索；
- 两种搜索方式均支持尺寸筛选；
- 报价单使用右下角悬浮圆球，不遮挡商品列表；
- 一个托盘可包含多个 SKU；
- 同一 SKU 可分布于多个托盘；
- 成交前不扣库存；
- 确认成交后扣减来源托盘库存；
- SKU 总库存自动汇总；
- 数据保存在浏览器本地，可通过右上角按钮重置。

## 文件说明

- `index.html`：页面结构；
- `styles.css`：移动端视觉样式；
- `app.js`：示例数据和报价、库存逻辑；
- `admin.html`：PC 管理后台；
- `admin.css`：PC 后台视觉样式；
- `admin.js`：商品、托盘、导入预览和销售管理逻辑；
- `data/手串商品与托盘库存_导入模板.xlsx`：Excel 导入模板。

本版本为前端流程验证 Demo，不包含真实账号、服务器数据库和 Excel 上传解析。
