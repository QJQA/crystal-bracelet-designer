# CRYSTAL STORE OS · 店铺 SaaS Demo

这是《手串报价与库存管理系统 PRD V0.2》的流程验证 Demo，包含手机报价端、PC 管理端和 Excel 商品导入模板。

## 入口

- `index.html`：手机报价端；
- `admin.html`：PC 管理端；
- `data/手串商品与托盘库存_导入模板.xlsx`：首次建档和批量导入模板。

从 `crystal` 总目录启动本地静态服务后，可访问：

```text
http://localhost:8765/store-saas/
http://localhost:8765/store-saas/admin.html
```

也可以直接双击对应 HTML 文件使用。

## 推荐演示流程

1. 输入托盘编号 `01`；
2. 选择尺寸 `8mm`，再选择“紫水晶 · 8mm”；
3. 输入数量并加入报价单；
4. 切换到“商品搜索”，输入“紫水晶”并选择尺寸；
5. 点击右下角报价单圆球，选择优惠金额或 5%/10%/15% 优惠比例并确认成交；
6. 进入“库存”，查看托盘库存与 SKU 总库存的同步变化；
7. 进入“销售记录”，查看成交明细。

## Demo 特性

- 托盘搜索与商品搜索并列，默认使用托盘搜索；
- 两种搜索方式均支持尺寸筛选；
- 报价单使用右下角悬浮圆球，不遮挡商品列表；
- 优惠支持直接填写金额，或按材料金额选择 5%、10%、15% 自动计算；
- 一个托盘可包含多个 SKU，同一 SKU 也可分布于多个托盘；
- 成交前不扣库存，确认成交后扣减来源托盘库存；
- SKU 总库存自动汇总；
- 数据保存在浏览器本地，可通过右上角按钮重置。

本版本为前端流程验证 Demo，不包含真实账号、服务器数据库和 Excel 上传解析。
